# 第三方许可文件来源

此目录保存第三方发行包中的许可原文；版权与许可归原作者所有。文件按原始字节复制，部分上游文件使用不同编码。

## 来源

- `PyMuPDF/`、`Pillow/`、`pywin32/`、`pyinstaller/`、`tkinterdnd2/`：当前安装版本的 wheel 中的许可文件；版本见 [第三方声明](../THIRD_PARTY_NOTICES.md)。
- `Python/LICENSE.txt`：当前 Python 3.13.12 安装目录中的 `LICENSE.txt`。
- `Tk/license.terms`：当前 Python 安装目录中的 `tcl/tk8.6/license.terms`。
- `tkdnd/license-header.txt`：tkinterdnd2 0.6.3 中 `tkinterdnd2/tkdnd/win-x64/tkdnd.tcl` 的文件头，完整保留版权与许可注释。
- `Tcl/license.terms`：[上游 Tcl 8.6 分支许可原文](https://raw.githubusercontent.com/tcltk/tcl/core-8-6-branch/license.terms)。
- `MuPDF/COPYING`：[上游 MuPDF 1.28.2 许可原文](https://raw.githubusercontent.com/ArtifexSoftware/mupdf/1.28.2/COPYING)。
- 根目录 `LICENSE`：[GNU 官方 AGPL v3 原文](https://www.gnu.org/licenses/agpl-3.0.txt)。
